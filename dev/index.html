Paramorph

Paramorph builds Julia objects whose fields live in constrained spaces while numerical algorithms operate on unconstrained Euclidean vectors. Start with the tutorial.

Paramorph.@paramorph — Macro
@paramorph struct MyStruct{N}
    a::asℝ₊
    b::UnitSimplex(N)
end

Define a structure whose fields are validated and transformed by TransformVariables.jl.

Paramorph.polytope — Function
polytope(A, b; center=zeros(...))

Map Euclidean coordinates bijectively to the interior of the bounded polytope A * y <= b, using radial projection from a strictly interior point. The map is piecewise smooth where the active facet changes.
